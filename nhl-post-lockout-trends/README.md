# NHL Post-Lockout Trends (2003–2023)

**Course:** DATA 605 Data Visualization, University of Calgary · **Author:** Riki Enquist
**Workbook:** [DATA605_NHL_Project.twbx](DATA605_NHL_Project.twbx). Open it in Tableau Desktop or the free Tableau Public.

## Question
How has the NHL game changed since the 2004–05 lockout and the rule changes that followed?

## Data
Season-by-season NHL skater stats (about 1,900 player-seasons) and goalie stats from 2003 to 2023, combined in Python. Both are included in the packaged workbook.

## Views
- **Scoring:** goals per game, assists per game and shots per game over time.
- **Goaltending:** save percentage and goals against.
- **Shooting efficiency:** goals compared with shots.
- **Physical play:** penalty minutes over time.
- **Roster age:** how player age has shifted.
