# Data Science Projects — Riki Enquist

Projects from my Master of Data Science and Analytics at the University of Calgary (2023–2024), covering forecasting, regression, statistical inference, SQL at scale and dashboarding in Python, R, SQL and Tableau.

I currently work as the sole data scientist at a 500+ employee North American trucking carrier. That work runs on company data, so it isn't published here.

| Project | Question | Methods | Tools |
|---|---|---|---|
| [Energy Price Forecasting](energy-price-forecasting/) | Can generation, demand and weather forecast hourly electricity prices in Spain? | Lasso feature selection, decision tree, gradient boosting, CNN, LSTM | Python, scikit-learn, TensorFlow |
| [Spotify Chart Regression](spotify-chart-regression/) | What makes a 2023 song chart on Spotify? | Multiple regression, stepwise and best-subset selection, interaction terms, assumption testing | R (olsrr, leaps, car, lmtest) |
| [MLB Power Hitting Analysis](mlb-power-hitting-analysis/) | Do power and plate discipline drive run production? | Bootstrap resampling, t-tests, chi-squared tests, linear regression | R (dplyr, ggplot2, mosaic) |
| [NHL Post-Lockout Trends](nhl-post-lockout-trends/) | How has the NHL game changed from 2003 to 2023? | Exploratory analysis, interactive dashboards | Python, Tableau |
| [Canadian Banking Transactions](canadian-banking-transactions/) | What seasonal patterns show up in Big 5 bank transactions with the Government of Canada? | SQL cleaning and aggregation, time-series EDA | MySQL, Python |
| [Corn Market Analysis](corn-market-analysis/) | How do weather, efficiency, stocks and biofuel demand shape the U.S. corn market? | Correlation and significance testing, ANOVA, futures basis analysis | Python (pandas, Matplotlib) |

Each folder has its own README with the question, data, approach and results.
